# Expense Tracker

## Description
A simple Expense Tracker application developed in Python. It allows users to manage their daily expenses by storing data in a text file.

## Features
- Add new expenses
- View all expenses
- Save expenses in a text file
- Simple command-line interface

## Technologies Used
- Python
- Text File Handling

## Files
- `expense.py` - Main program
- `expenses.txt` - Stores expense records
